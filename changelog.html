Always-On Lateral (AOL)

openpilot이 disengage 되어도 lateral(조향) 제어를 계속 유지하는 기능.

Driver brake/gas override → openpilot disengage
                                    │
                              AOL enabled?
                              ╱          ╲
                           Yes            No → lateral 해제
                            │
                    Lateral-only 유지
                            │
            ┌───────────────┼────────────────┐
            │               │                │
     Temp fault      High-speed       Standstill
     1s debounce    steer fault       5초 후 해제
     유지             1s debounce       brake hold 시
                     유지               즉시 해제

control Lateral-Only 제어

FrogPilot의 Hyundai lateral-only 동작을 포팅. Disengage 상태에서 longitudinal(가감속)은 드라이버에게 넘기고, lateral(조향)만 openpilot이 유지. 저속 engage 및 steering 제한도 완화되어 있음.
selfdrive/controls/controlsd.py selfdrive/car/hyundai/carcontroller.py

control Safety Wiring & Heartbeat

  • panda safety layer에 AOL 연결 — disengage 상태에서도 lateral CAN 메시지가 safety check 통과
  • pandad heartbeat를 AOL 활성 시 engaged로 유지 — heartbeat timeout으로 인한 AOL 해제 방지
selfdrive/pandad/pandad.py

control Temp Fault Debounce

Hyundai MDPS가 발생시키는 일시적 steering fault를 1초간 debounce 처리. 주행 중(moving) fault가 깜빡여도 lateral 제어가 끊기지 않음. 고속에서 steerUnavailable flicker도 controlsd 레벨에서 debounce.
selfdrive/controls/controlsd.py

control Standstill 처리

  • 정차 시 AOL lateral을 즉시 해제하지 않고 5초 delay 후 해제
  • 주행 중 lateral drop 시 3초간 hold하여 일시적 끊김 방지
  • 브레이크 홀드 진입 시에는 불필요한 조향 차단

UI TPMS 위젯

좌측 상단 set-speed 박스 아래에 차체 상면도(top-view) 사각형을 그리고, 네 모서리에 FL/FR/RL/RR 공기압을 PSI 정수로 표시.
  • 데이터 소스: carState.tpms.fl/fr/rl/rr
  • 너비 200px — set-speed 박스와 좌측 정렬
  • 차체 내부에 "PSI" 단위 라벨
  • 우측 상단에 한 줄 요약도 별도 표시: TPMS 38/39 38/39

UI 회전 그래픽 나침반

TPMS 위젯 아래에 원형 나침반 (반지름 110px). GPS bearing에 따라 N/E/S/W 라벨과 눈금이 회전.
  • 30° 간격 눈금 (cardinal 방위는 굵게)
  • N은 빨간색, E/S/W는 흰색
  • 12시 고정 삼각형 = 현재 진행 방향
  • 중앙에 방위각 숫자 (예: 045°)
  • GPS 소스: gpsLocationExternal 우선, 없으면 gpsLocation으로 fallback
  • GPS 미수신 시 "---" 표시
