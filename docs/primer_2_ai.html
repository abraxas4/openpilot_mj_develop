AI / ML이란?

AI vs ML vs 딥러닝

세 개가 포함 관계입니다:

  ┌─────────────────────────────────────────────────────┐
  │  AI (인공지능)  — 컴퓨터가 지능적으로 보이는 모든 것      │
  │  ┌───────────────────────────────────────────────┐  │
  │  │  ML (기계학습)  — 데이터로 스스로 규칙을 찾는 것   │  │
  │  │  ┌─────────────────────────────────────────┐  │  │
  │  │  │  딥러닝  — 신경망을 쌓아 학습하는 ML     │  │  │
  │  │  │  (openpilot이 여기 해당)                │  │  │
  │  │  └─────────────────────────────────────────┘  │  │
  │  └───────────────────────────────────────────────┘  │
  └─────────────────────────────────────────────────────┘

전통 프로그래밍: 개발자가 규칙을 직접 코드로 작성. "앞차가 40m 이내이면 브레이크"

ML: 수백만 건의 주행 데이터를 주면, 컴퓨터가 스스로 규칙을 찾아냄.

openpilot 적용: comma.ai는 차선 인식 규칙을 직접 코드로 짜지 않았습니다.
수천만 km의 주행 영상을 신경망에 학습시켜, 신경망이 스스로 "차선이 무엇인지" 찾아내게 했습니다.

신경망 (Neural Network) 기초

뉴런 (Neuron) / 노드

신경망의 가장 작은 단위입니다. 여러 입력을 받아, 가중합을 계산하고, 결과를 출력합니다.

// 뉴런 하나를 C로 표현하면:
float neuron(float inputs[], float weights[], int n, float bias) {
    float sum = bias;
    for (int i = 0; i < n; i++)
        sum += inputs[i] * weights[i];   // 가중합
    return activation(sum);              // 활성화 함수 통과
}
비유: ATM의 지폐 감별 센서와 유사합니다.
여러 센서값(빛 투과율, 두께, 자성...)을 받아 → 각 특징에 가중치 적용 → 진짜/위조 판별.
가중치 (Weight) / 편향 (Bias)

뉴런의 각 입력에 곱해지는 계수가 가중치(W)입니다. 입력 없이 더해지는 상수가 편향(b)입니다.

  출력 = W1×입력1 + W2×입력2 + W3×입력3 + b

  예) 차선 인식 뉴런:
  차선_점수 = 0.8×밝기 + (-0.3)×색상_빨강 + 0.5×직선성 + 0.1

  W = [0.8, -0.3, 0.5]  // 가중치 (학습으로 결정됨)
  b = 0.1               // 편향 (학습으로 결정됨)

이 W와 b 값이 "학습"으로 결정됩니다. openpilot 모델은 이미 학습이 완료된 W,b값들을 파일에 저장해 사용합니다.

레이어 (Layer)

뉴런 여러 개를 나란히 모은 것이 레이어입니다. 레이어를 여러 개 쌓으면 "깊은(Deep)" 신경망이 됩니다.

  입력       Layer 1      Layer 2      출력
  ┌────┐   ┌────────┐   ┌────────┐   ┌────┐
  │이미지│──▶│특징추출│──▶│패턴인식│──▶│차선 │
  │픽셀 │   │(64뉴런)│   │(128   │   │위치 │
  │     │   │        │   │뉴런)   │   │     │
  └────┘   └────────┘   └────────┘   └────┘

  * 앞 레이어: 단순한 특징 (엣지, 선)
  * 뒤 레이어: 복잡한 특징 (차선, 차량, 도로)

Training vs Inference

Training (학습)

수백만 개의 예제를 보여주며 W,b를 자동으로 찾는 과정.

몇 주~몇 달이 걸리고, 수천 개의 GPU가 필요합니다.

comma.ai 서버에서 진행. 기기에서는 불가.

Inference (추론)

이미 학습된 W,b를 이용해 새 입력에 대해 결과를 계산하는 것.

매우 빠름 (20ms 이내). 기기에서 실행.

openpilot이 주행 중 하는 것이 바로 이것.

openpilot 비유:
Training = 공장에서 ATM 지폐 감별기를 "교육"하는 것 (수만 장의 진폐/위폐 학습)
Inference = 현장에서 고객 지폐를 실시간으로 판별하는 것

사전학습 모델 / Pre-trained Model

사전학습 모델 Pre-trained Model

이미 학습이 완료된 신경망을 파일로 저장한 것입니다. openpilot의 driving_policy.onnx가 이것입니다.

이 파일에는 수십억 개의 W,b 숫자가 저장되어 있습니다. 기기는 이 파일을 불러와 실행만 합니다.

비유: 임베디드 펌웨어에서 ROM에 구워진 캘리브레이션 테이블과 같습니다.
공장(comma.ai)에서 만든 테이블을 현장(차 안)에서 조회만 하는 것.

ONNX 포맷

ONNX Open Neural Network Exchange

신경망 모델을 저장하는 표준 파일 포맷입니다. 어떤 학습 프레임워크(PyTorch, TensorFlow 등)로 만들어도 ONNX로 변환하면 다른 환경에서 실행 가능합니다.

  // ONNX 파일에 담긴 것:
  1. 그래프 구조: 어떤 연산을 어떤 순서로 할지
     Conv → BatchNorm → ReLU → Conv → ...
  2. 가중치: 각 연산의 W, b 값 (수백 MB)
  3. 입출력 명세: 텐서 이름, shape, dtype
openpilot 적용:
driving_supercombo.onnx (또는 driving_vision.onnx)
→ tinygrad가 이를 읽어 Adreno 630 GPU용 코드로 변환해 실행합니다.

Loss / Gradient (학습 원리 이해용)

Loss — 오차/손실

신경망 출력과 정답의 차이를 숫자로 표현한 것입니다. 학습의 목표는 Loss를 최소화하는 W,b를 찾는 것입니다.

  // 예시: 앞차 거리 예측
  신경망 출력: 32.5m
  실제 거리:   30.0m
  Loss = (32.5 - 30.0)² = 6.25

  Loss가 작을수록 신경망이 잘 학습된 것.
Gradient Descent — 경사 하강법

Loss를 줄이는 방향으로 W,b를 조금씩 수정하는 알고리즘입니다. "산에서 경사를 따라 내려가는" 것과 같습니다.

      Loss
        │
    높음│ ●  ← 현재 W값
        │  ↘
        │    ●
        │      ↘
    낮음│        ● ← 최적 W값 (Loss 최소)
        └──────────────────── W값
         나쁜             좋은

  매 학습 step마다 W를 Loss가 줄어드는 방향으로 조금 이동
openpilot과의 관계: Training 시에만 해당.
기기에서 Inference할 때는 W가 고정되어 변하지 않습니다.

Feature / Label

Feature — 특징/입력 데이터

신경망에 입력하는 데이터입니다. 카메라 이미지 픽셀값, 속도, 조향각 등이 Feature입니다.

openpilot: 카메라 영상(img_q), 이전 상태(features_buffer), 차선변경 의도(desire_q) 등이 Feature입니다.

Label — 정답 데이터

Training 시 "정답"으로 사용하는 값입니다. openpilot에서는 사람 드라이버의 실제 조향값, 브레이크 타이밍 등이 Label로 사용됩니다.

openpilot Training 예시:
Feature: 카메라 프레임
Label: 그 순간 사람이 실제로 조향한 각도, 가속페달 양
→ "이 화면을 보면 이렇게 운전해야 한다"를 학습

Hypothesis — 가설

다중 가설 출력

하나의 답 대신 여러 가능한 답(가설)을 확률과 함께 출력하는 방식입니다. 불확실한 상황에서 더 안전합니다.

  단일 출력 (기존):
  "앞차까지 거리: 45.0m"

  다중 가설 출력 (MDN):
  가설1: 45.0m (확률 70%)  ← 주된 경로: 직진 차선
  가설2: 22.0m (확률 20%)  ← 옆 차선 끼어들기
  가설3: 80.0m (확률 10%)  ← 앞차 없음
openpilot 적용: lead 출력이 3개(leadsV3[0~2])인 이유가 여기에 있습니다.
가장 확률 높은 앞차([0])를 주로 사용하고, 나머지는 보조 정보입니다.
