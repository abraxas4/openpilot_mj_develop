4. tinygrad 내부 알고리즘

ONNX → GPU 실행까지 5단계

1. ONNX 파싱  (tinygrad/nn/onnx.py)
   OnnxPBBufferedReader → computational graph 추출
   · Nodes: Conv, Reshape, MatMul, LSTM, LayerNorm 등 200+ 연산자
   · Initializers: 가중치 & 바이어스 텐서
   · Inputs/Outputs: 텐서 명세 (이름, shape, dtype)

        ↓

2. Tinygrad IR 변환
   ONNX op → tinygrad Tensor 연산 매핑
   예) ONNX Conv → Tensor.conv2d()
       ONNX LSTM → Tensor.lstm() (unrolled)
       ONNX Softmax → Tensor.softmax()

        ↓

3. JIT 컴파일  (TinyJit, compile_modeld.py)
   · 3회 warm-up 실행으로 GPU 커널 추출
   · prune=True: 불필요한 연산 제거
   · 직렬화 → driving_tinygrad.pkl (external buffer 지원)
   · 이후 실행은 컴파일된 커널 직접 디스패치

        ↓

4. 디바이스별 렌더링  (tinygrad/runtime/ops_qcom.py)
   QCOMCLRenderer → OpenCL 스타일 컴퓨트 셰이더 생성
   IR3Renderer    → Adreno IR3 ISA 어셈블리 생성
   PKT7/PKT4 패킷 → GPU Command Buffer 구성

        ↓

5. GPU 실행  (Adreno 630, KGSL IOCTL)
   QCOMComputeQueue.exec() → KGSL ioctl 제출
   THREAD64 모드, Cache flush, Memory barrier
   결과 → CPU 메모리 전송
tinygrad_repo/tinygrad/nn/onnx.py tinygrad_repo/tinygrad/runtime/ops_qcom.py openpilot/selfdrive/modeld/compile_modeld.py

출력 파싱 알고리즘 (MDN)

모델은 Mixture Density Network(MDN) 방식으로 출력. 단일 예측이 아닌 여러 가설(hypothesis)의 분포를 출력.

# parse_model_outputs.py: MDN 파싱
def parse_mdn(raw, n_hypotheses):
    n_values = (raw.shape[2] - n_hypotheses) // 2

    pred_mu  = raw[:, :, :n_values]               # 평균 궤적
    pred_std = exp(raw[:, :, n_values:2*n_values]) # 표준편차 (log-space)
    weights  = softmax(raw[:, :, -n_hypotheses:])  # 가설 가중치

    # 가중치 기준 정렬 (가장 확률 높은 가설 = [0])
    sort_idx = argsort(weights, descending=True)
    return pred_mu[sort_idx], pred_std[sort_idx], weights[sort_idx]

# 이진 출력 (lane_lines_prob, lead_prob, meta)
prob = sigmoid(raw)

# 범주형 출력 (desire_state, desire_pred)
dist = softmax(raw, axis=-1)

순환 연결 (Temporal Context)

매 프레임 hidden_state를 다음 프레임에 피드백하여 시계열 문맥 유지.

# modeld.py: 매 프레임
model_output = policy_jit(img_q, big_img_q, feat_q, desire_q, packed_npy)

# 출력 → 다음 입력으로
npy['prev_feat'] = model_output[hidden_state_slice]  # (1, 512)

# features_buffer: 24프레임 롤링 윈도우
feat_q['features_buffer'] = rolling_window(npy['prev_feat'], size=24)
# → (1, 24, 512): 약 1.2초(24프레임 × 50ms)의 문맥 보존
