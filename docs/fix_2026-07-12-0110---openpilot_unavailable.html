1. 증상

증상 차량 탑승 후 openpilot GUI 및 카메라 화면은 정상 표시. 그러나 "openpilot unavailable" 메시지가 계속 표시되며 engage 불가.

upstream merge (commaai/openpilot → frogpilot_port) 이후 첫 실차 테스트에서 발생.

2. 조사 과정 & 사용 도구

ls swaglog 목록 확인

ls -lt /data/log/ | head -10

결과: 최신 드라이브 세그먼트 = 000001db--caae7c20d0--0,1 (Jul 12 00:55~00:56)
strings swaglog 텍스트 추출
swaglog는 msgpack 바이너리. msgpack 모듈이 없어 strings 명령으로 읽을 수 있는 텍스트 추출. 
strings /data/log/swaglog.0000013104 | grep -iE "unavail|error|harness|fingerprint"
panda 상태 확인: harnessStatus: "notConnected", ignitionLine: false → 이 로그는 오프로드(차 밖) 시점이었음. 별도 확인 필요.
openpilot LogReader rlog 분석
openpilot 자체 라이브러리로 압축 rlog를 파싱하여 메시지 타입 확인. 
python3 -c "
from openpilot.tools.lib.logreader import LogReader
lr = LogReader(\"/data/media/0/realdata/000001db--caae7c20d0--0/rlog.zst\")
types_seen = set()
for msg in lr:
    types_seen.add(msg.which())
print(sorted(types_seen))
"
결과 (주목할 부재): carParams, carState, controlsState, selfdriveState, modelV2 — 모두 없음.
→ card.py가 carParams를 publish하지 못했음을 확인.
LogReader errorLogMessage 추출
rlog 안의 에러 메시지를 daemon 별로 필터링. 
python3 -c "
for msg in LogReader(rlog):
    if msg.which() == 'errorLogMessage':
        d = json.loads(msg.errorLogMessage)
        if 'card' in d.get('ctx',{}).get('daemon',''):
            print(d.get('msg'), d.get('exc_info','')[:500])
"

3. 근본 원인

흐름

차 시동 ON
  ↓
card.py 시작 → ISO-TP 쿼리 (일부 ECU는 0x7f22 negative response → 정상)
  ↓
CAN fingerprint 성공: HYUNDAI_AZERA_HEV_6TH_GEN ✓
  ↓
car.py __init__() 에서 CP 설정 시:
  self.CP.alternativeExperience |= ALTERNATIVE_EXPERIENCE.ALWAYS_ON_LATERAL
  ↓
AttributeError: 'ALWAYS_ON_LATERAL' not found → crash
  ↓
carParams 메시지 미전송 → selfdrived가 car 인식 못함
  ↓
"openpilot unavailable" 표시

왜 제거됐나?

upstream commaai/opendbc (930eeb14)에서 panda safety 코드 재구성 시 ALWAYS_ON_LATERAL 상수가 더 이상 쓰이지 않는 것으로 판단해 제거. 우리 card.py는 FrogPilot 포팅 시 추가한 AOL 코드에서 이 상수를 참조 중이었음.

panda 펌웨어(9da8467a)는 이 비트를 실제로 체크하지 않음. 실제 AOL 동작은 pandad.cc의 heartbeat 로직으로 제어. 상수가 없으면 crash만 발생하고 기능적 영향은 없음.

4. 수정

fix abraxas4/opendbc — ALWAYS_ON_LATERAL 상수 복원

panda 펌웨어가 체크하지 않는 비트이므로, 충돌하지 않는 값(128 = 0x80)으로 복원.

# opendbc_repo/opendbc/safety/__init__.py
class ALTERNATIVE_EXPERIENCE:
  DEFAULT = 0
  DISABLE_STOCK_AEB = 2
  RAISE_LONGITUDINAL_LIMITS_TO_ISO_MAX = 8
  ALLOW_AEB = 16
+ ALWAYS_ON_LATERAL = 128  # enable AOL in panda safety
opendbc_repo/opendbc/safety/__init__.py
