1. 증상

증상 90도로 꺾인 외길을 저속으로 진입. 스티어링은 AOL (Always On Lateral, 상시 횡제어) 로 살아 있고, UI (User Interface, 사용자 화면) 에는 꺾인 길이 잘 그려진다. 그런데 스티어링 휠이 90도까지 돌아가지 않는다.

당시 설정: Experimental Mode (실험 모드) 켜짐.

2. 약어 풀이

본문에서 약자를 쓸 때는 한글을 병기합니다. 한눈에 보기 위한 표입니다.

약어원문한글이 문서에서 하는 역할
AOL Always On Lateral 상시 횡제어 크루즈가 꺼져 있어도 조향을 유지. 저속에서도 latActive를 살림.
UI User Interface 사용자 화면 모델이 본 경로·차선을 그림. 조향 명령과는 다른 신호.
e2e end-to-end 종단간 제어 실험 모드에서 종방향 가속도를 모델이 직접 냄. 횡조향은 바꾸지 않음.
MPC Model Predictive Control 모델 예측 제어 실험 모드가 꺼져 있을 때 쓰는 종방향 계획기.
EPS Electric Power Steering 전동식 파워 스티어링 현대차에서 조향각 90도 이상을 1초 넘게 토크로 유지하면 고장 판정.
LKAS Lane Keeping Assist System 차선 유지 보조 조향 토크를 보내는 CAN 메시지. steer_req 비트가 활성 요청.
CAN Controller Area Network 차량 내부 통신 버스 토크 명령이 조향 ECU로 나가는 경로.
PID Proportional-Integral-Derivative 비례-적분-미분 제어 토크 횡제어기. 저속에서는 I항(적분)을 멈춤.
FF Feedforward 피드포워드 / 앞먹임 목표 횡가속도를 토크로 바로 환산. FF ≈ κ · v².
vEgo ego vehicle speed 자차 속도 제어 루프의 현재 차속 (m/s).
곡률 κ curvature 곡률 (1/m) 회전 반경의 역수. 조향 명령의 실제 단위.
횡가속도 lateral acceleration 옆방향 가속도 (m/s²) 지금 옆으로 얼마나 세게 도는지. a = κ · v².
횡저크 lateral jerk 횡가속도의 변화 속도 (m/s³) 휠을 얼마나 빨리 더 꺾어도 되는지. clip의 레이트 제한.
action model action 모델의 즉시 조작 명령 지금 넣을 곡률·가속도. UI 경로(position)와 다른 출력.
ISO International Organization for Standardization 국제표준화기구 횡가속도 3.0 m/s², 횡저크 5.0 m/s³ 상한의 근거.
latActive lateral active 횡제어 활성 조향 루프가 실제로 토크를 내도 되는지.
steer_req steer request 조향 요청 비트 LKAS 메시지에서 “지금 조향한다”는 플래그.
ECU Electronic Control Unit 전자 제어 장치 여기서는 조향 EPS 쪽 제어기.
PathSteerHelper path steer helper 경로 조향 보조 UI 경로가 안정되면 그 곡률을 저속 조향 목표에 섞음.
speed_blend speed blend 속도 선형 혼합 30 km/h에서 0, 80 km/h에서 1. 경로 비중과 상한에 사용.

3. 사실

사실 실험 모드는 이번 현상과 관계없습니다.

스티어링 휠이 90도까지 안 돈 이유는 clip_curvature 의 max 계수입니다. 변경 전 고정값:

  • 허용 횡가속도 MAX_LATERAL_ACCEL_NO_ROLL = 3.0 m/s²
  • 허용 횡저크 MAX_LATERAL_JERK = 5.0 m/s³
  • 절대 곡률 캡 MAX_CURVATURE = 0.2 /m

조향 목표는 곡률 κ 이고, 허용 조향은 대략 κ ≤ a_max / v² 로 잘립니다. 서행 30 km/h에서 a_max=3.0 이면 κ 상한 약 0.043 (휠 약 90도, 반경 약 23 m). 직각 외길에 필요한 조향보다 작습니다.

UI는 modelV2.position 을 그리므로 길은 그대로 보입니다. 휠 명령은 위 계수로 clip된 곡률입니다.

vEgo ≤ 0.3 m/s (약 1.1 km/h) 곡률 동결은 서행과 무관합니다.

적용 후 그 max 계수를 속도별로 바꿨습니다.

  • 30 km/h 이하: 횡가속도 5.0 m/s², 횡저크 8.0 m/s³. UI 경로가 안정되면 그 경로 곡률을 조향 목표에 사용.
  • 80 km/h 이상: 횡가속도 3.6 m/s², 횡저크 6.0 m/s³ (스톡 대비 +20%).
  • 30~80 km/h: 위 두 값 사이를 선형.
  • MAX_CURVATURE = 0.2 절대 캡은 그대로.

상세는 11절.

도로 90도 ≠ 스티어링 휠 90도

휠 90도는 현대차 대략 wheelbase 2.7 m, steerRatio 13.7 기준 곡률 약 0.04 (반경 약 24 m) 입니다. 골목 직각은 보통 휠 각이 그보다 큽니다. 로그로 확인할 값은 action.desiredCurvature 와 controlsState.desiredCurvature 입니다.

5. 실험 모드 — 이번 현상과 무관

Experimental Mode (실험 모드) 는 selfdriveState.experimentalMode 플래그입니다. 종방향 계획기만 갈리므로, UI에 길이 보이는데 휠이 덜 도는 현상과는 관계없습니다.

항목실험 모드가 하는 일이번 현상과
종방향 가속도 min(e2e 가속도, MPC 가속도). 횡조향 값은 안 바꿈. 무관.
모델 횡곡률 desiredCurvature 없음. 같은 모델, 같은 action. 무관.
clip_curvature 없음. 실험 모드와 무관. 무관.
AOL 저속 유지 없음. AOL이 따로 latActive를 살림. 무관.
Hyundai MAX_ANGLE = 85 없음 무관.
관련 코드 — 실험 모드는 종방향만
# openpilot/selfdrive/controls/lib/longitudinal_planner.py
if sm['selfdriveState'].experimentalMode:
    output_a_target = min(output_a_target_e2e, output_a_target_mpc)  # 종방향만
    self.output_should_stop = output_should_stop_e2e or output_should_stop_mpc
else:
    output_a_target = output_a_target_mpc

7. 있는 제한들 (변경 전)

조향각 90도 하드 캡은 없습니다. 곡률·가속도·토크·EPS 보호가 겹칩니다. 아래 숫자는 변경 전 스톡 값입니다. 적용된 스케줄은 11절을 보면 됩니다.

제한값어디서저속 90도에서 의미
곡률 동결 vEgo ≤ 0.3 m/s modeld 약 1.1 km/h 이하에서만. 서행에는 해당 없음.
MAX_CURVATURE 0.2 /m (반경 5 m) clip_curvature 저속에서 바인딩되는 곡률 캡. 휠 90도 캡은 아님. 현대 기준 휠 90도는 대략 κ≈0.04.
MAX_LATERAL_ACCEL_NO_ROLL 3.0 m/s² clip_curvature · ISO 계산 속도를 최소 1.0 m/s로 올려서, 저속에선 0.2 곡률 캡보다 헐거움.
MAX_LATERAL_JERK 5.0 m/s³ clip_curvature · ISO 곡률이 한 제어 주기(10 ms)에 커질 수 있는 양. 급격한 직각 진입을 완만하게 만듦.
토크 FF a = κ · v² LatControlTorque 저속에선 목표 횡가속도가 작아 앞먹임 토크가 약함.
PID 적분항 동결 vEgo < 5 m/s LatControlTorque 약 18 km/h 아래에서 I항이 휠을 더 밀어주지 못함.
토크 레이트 STEER_DELTA_UP 2~3 / 10ms Hyundai carcontroller + panda 토크가 한 번에 점프하지 못하게 함.
MAX_ANGLE 85도, 89프레임 Hyundai carcontroller 이미 85도 근처까지 간 뒤에 EPS 보호 펄스. 처음부터 안 도는 원인 아님.

대략 환산 (wheelbase 2.7 m, steerRatio 13.7 가정, 저속 기구학)

  • 휠 90도 ≈ 도로륜 약 6.6도 ≈ 곡률 0.04 ≈ 반경 24 m
  • MAX_CURVATURE = 0.2 ≈ 반경 5 m ≈ 휠 약 400도 부근 (풀락에 가까움)

서행에서 휠이 90도까지도 안 갔다면 0.3 m/s 동결이 아닙니다. action.desiredCurvature 크기와 clip 이후 값을 보면 됩니다.

9. Hyundai EPS 85도 펄스

현대/기아 EPS (Electric Power Steering, 전동식 파워 스티어링) 는 조향각 90도 이상에서 토크를 1초 넘게 넣으면 고장 납니다. 코드는 각도를 85도에서 자르지 않고, 요청 비트를 잠깐 끊어서 타이머를 리셋합니다.

12. 속도 스케줄 (30 / 80 km/h, 중간 선형)

t = speed_blend(vEgo) 는 30 km/h 이하에서 0, 80 km/h 이상에서 1, 그 사이는 선형입니다. 경로 추종 비중은 1 − t 입니다.

15. action이란

action은 주행 모델이 지금 차에 넣으라고 내는 짧은 조작 명령입니다. 화면의 길과 다른 출력입니다.

출력의미어디에 쓰이나
modelV2.position / 차선 앞으로 몇 초의 예측 경로 UI가 그리는 길
modelV2.action 지금 넣을 횡·종 명령 조향·가감속 제어

action 안에는 desiredCurvature(조향 곡률)와 desiredAcceleration(종방향 가속도)가 있습니다. 모델이 낸 횡방향 값을 속도²로 나눠 곡률로 바꿉니다. 

# openpilot/selfdrive/modeld/modeld.py
desired_curvature = model_output['action'][0,0] / (max(1.0, v_ego))**2

변경 전에는 화면이 90도 길을 그려도 action 곡률이 작으면 휠이 그만큼만 돌아가려 했습니다. 이번 변경이 그 점을 푸는 것입니다. 서행·중속에서 UI 경로가 안정되면 조향 목표를 action만이 아니라 그 경로 곡률로 엽니다.

16. 횡저크(jerk)와 30~80 km/h

횡가속도는 지금 옆으로 얼마나 세게 도는지입니다. 횡저크는 그 세기가 얼마나 빨리 변하는지 (m/s³) 입니다. clip에서 저크는 한 제어 주기(10 ms)에 곡률이 얼마나 변해도 되는지의 레이트 제한입니다. 상한(횡가속도)이 “최대 얼마나 꺾을 수 있나”라면, 저크는 “그 각까지 얼마나 빨리 가도 되나”입니다.

30~80 km/h는 고속보다 특별히 위험한 구간이 아닙니다. 기존과 달라진 점이 두 가지입니다.

변경 전지금 (예: 55 km/h 중간)
조향 목표 action만 경로가 안정되면 경로 50% + action 50%
횡가속도 상한 3.0 m/s² 4.3 m/s²
횡저크 상한 5.0 m/s³ 7.0 m/s³
  1. UI 경로를 일부 따라감 (새 동작). 30 km/h에서 안정 시 100%, 80 km/h에서 0%, 사이는 선형.
  2. 상한이 예전 3.0 / 5.0보다 큼. 30에 가까울수록 5.0 / 8.0, 80에 가까울수록 3.6 / 6.0.

80 km/h 이상은 경로 혼합이 0이라, 달라진 것은 상한 +20%뿐입니다. 30~80에서 경로가 안정 판정을 통과하고 action보다 훨씬 큰 곡률이면 예전보다 그쪽으로 가지만, 저크 제한을 타고 올라갑니다.

17. 고속 급변경이 되나

고속에서 바퀴가 한 번에 5도 이상 더 꺾이는 급변경은 이번 코드가 하는 일이 아닙니다. +20%는 지금 각에 5도를 더하는 것이 아니라 상한을 20% 올리는 것입니다. 모델이 더 꺾으라고 하지 않으면 휠은 그대로입니다.

변경 전적용 후 (80 km/h)
허용 횡가속도3.0 m/s²3.6 m/s²
허용 횡저크5.0 m/s³6.0 m/s³
휠 5도만큼 곡률을 키우는 데 (대략)~0.23 s~0.19 s

5도를 한 프레임에 넣는 경로는 없습니다. 현대차 토크 레이트(STEER_DELTA_UP)도 그대로입니다. 속도 경계에서 계수가 계단처럼 바뀌지 않고 30~80은 선형입니다.

상한을 넓힌 만큼 예전보다 커브를 조금 더 세게/빠르게 따라갈 수는 있습니다. 형태는 다음과 같습니다.

  • 고속에서 모델이 이미 예전 3.0에 붙어 있던 커브 → 이제 3.6까지 허용.
  • 30~80 km/h에서 안정된 UI 경로를 일부 믿음. 틀린 길이 안정적으로 보이면 예전보다 그쪽으로 감.
  • 30 km/h 이하 직각은 의도적으로 더 꺾게 만든 구간.

요약

  1. 실험 모드는 이번 현상과 관계없습니다.
  2. 휠이 90도까지 안 돈 이유는 clip_curvature max 계수 (횡가속도 3.0, 횡저크 5.0, 곡률 0.2).
  3. 적용 후: 30 km/h 이하 5.0 / 8.0 + 안정 UI 경로 조향. 80 km/h 이상 +20% (3.6 / 6.0). 사이는 선형.
  4. action은 즉시 조작 명령, UI 경로와 다름. 이번 변경이 서행에서 경로를 조향에 쓰는 이유.
  5. 고속 5도 순간 급변경은 없음. 저크·토크 레이트가 남음. 상한만 넓힘.
