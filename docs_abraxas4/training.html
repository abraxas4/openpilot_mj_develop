openpilot — 학습 및 트레이닝 가이드

abraxas4/openpilot_mj_develop · 실제 코드베이스 기반 분석 · Hyundai Azera HEV 6th Gen

⚠️ openpilot의 학습은 두 가지로 나뉩니다: 자동 학습(주행하면 자동으로 적용되는 물리 파라미터 추정)과 신경망 재학습(불가 — 모델은 사전학습되어 고정됨). 운전 습관을 직접 학습시키는 기능은 현재 없습니다.

전체 구조 개요

                     ┌─────────────────────────────────────┐
                     │         주행 중 자동 학습 (Layer 1~4) │
                     └─────────────────────────────────────┘

  카메라 ──▶ calibrationd  ──▶ CalibrationParams  (카메라 장착 각도)
  GPS/IMU ──▶ paramsd        ──▶ LiveParametersV2   (스티어링비, 타이어 강성)
  MDPS ──▶   torqued        ──▶ LiveTorqueParameters (토크-횡가속도 매핑)
  CAN ──▶    lagd           ──▶ (지연 추정, 캐시 없음)

              ↓ 실시간 반영 (매 프레임)
         controlsd  ←→  LateralMPC / LongMPC
              ↓
         CAN 출력 (조향/가감속)


                     ┌─────────────────────────────────────┐
                     │      신경망 모델 (고정, 학습 불가)      │
                     └─────────────────────────────────────┘

  카메라 ──▶ driving_vision.onnx (46MB)  ──▶ 차선/전방차/경로 인식
             driving_policy.onnx (14MB) ──▶ 조향/가감속 명령
             dmonitoring_model.onnx      ──▶ 운전자 상태 인식
             ↑
     comma.ai 서버에서 사전학습된 모델 (변경 불가)


                     ┌─────────────────────────────────────┐
                     │        데이터 업로드 (단방향)           │
                     └─────────────────────────────────────┘

  주행 로그 ──▶ uploader.py ──▶ api.commadotai.com  (comma.ai 서버 학습용)
                                          ↓
                              comma.ai 서버에서 다음 버전 모델 학습
                              (개인 맞춤 아님, 피드백 없음)

🟢 자동 학습 — 주행하면 자동 적용

아무것도 하지 않아도 주행 중 자동으로 추정/기억됩니다.

자동 Layer 1 — 카메라 보정 (calibrationd)

카메라의 장착 각도(Roll/Pitch/Yaw)와 높이를 비주얼 오도메트리로 자동 추정.
  • 고속도로 직선 주행 5블록 이상 시 calibrated 상태 도달
  • 최대 50블록까지 계속 정밀화
  • ~50초마다 CalibrationParams에 저장, 재시동 후에도 유지
selfdrive/locationd/calibrationd.py

자동 Layer 2 — 차량 동역학 파라미터 (paramsd)

확장 칼만 필터(EKF)로 차량 고유 파라미터를 실시간 추정. 가장 중요한 자동 학습 레이어.
  • 스티어링 비율(steerRatio) — 핸들 각도 대비 조향량
  • 타이어 강성 계수(stiffnessFactor) — 노면/타이어 상태 반영
  • 스티어링 각도 오프셋 — 센서 바이어스 보정
  • 도로 경사(roll) — 편도로 경사 추정

steerRatio·각도 오프셋은 재시동 후에도 유지. stiffnessFactor는 매 주행마다 1.0으로 초기화 (노면 조건 가정). ~60초마다 LiveParametersV2에 저장.

selfdrive/locationd/paramsd.py selfdrive/locationd/car_kf.py

자동 Layer 3 — 토크 파라미터 학습 (torqued)

조향 토크 vs. 횡가속도 관계를 데이터 버킷팅으로 선형 피팅. 토크 기반 제어 차량에 적용.
  • 횡가속도 계수(latAccelFactor)
  • 횡가속도 오프셋(latAccelOffset)
  • 마찰 계수(friction) — 타이어 히스테리시스에서 추정
  • 최소 4,000개 데이터 포인트 수집 후 유효화
  • ~60초마다 LiveTorqueParameters에 저장
selfdrive/locationd/torqued.py

자동 Layer 4 — 제어 지연 추정 (lagd)

조향 명령과 실제 차량 반응 사이의 시간 지연을 FFT 교차상관으로 추정. 피드포워드 제어의 지연 보상에 활용. 캐시에 저장되지 않음.
selfdrive/locationd/lagd.py

🔧 수동 튜닝 — 직접 설정 가능한 항목

코드 또는 파라미터를 직접 수정하여 주행 특성을 조정하는 방법.

수동 종방향 제어 파라미터 (longcontrol)

가감속 응답 특성은 차량별 고정 PID 파라미터로 결정됨. 자동 학습 없음.
  • kP/kI breakpoint 테이블 수정으로 응답성 조정
  • 앞차 추종 거리: long_mpc.py의 비용 함수 가중치
  • 가감속 프로파일: longitudinalPlan의 속도/가속도 제한
selfdrive/controls/lib/longcontrol.py selfdrive/controls/lib/longitudinal_mpc_lib/long_mpc.py

수동 횡방향 제어 파라미터 (latcontrol_torque)

Azera는 토크 기반 제어 사용. Layer 3 자동 학습 외에 기준값을 수동으로 설정 가능.
  • STEER_THRESHOLD, STEER_DRIVER_ALLOWANCE 등
  • 현재 값: STEER_THRESHOLD=150, STEER_DRIVER_ALLOWANCE=50
selfdrive/controls/lib/latcontrol_torque.py opendbc_repo/opendbc/car/hyundai/values.py

수동 데이터 로그 오프라인 분석

comma 3x는 모든 주행을 rlog.zst / qlog.zst로 저장. PC에서 분석하여 제어 파라미터를 수동으로 개선 가능.
  • 60초 단위 세그먼트: 카메라(HEVC), CAN, 센서 데이터 포함
  • tools/lib/route.py로 로그 접근
  • tools/plotjuggler/로 시각화
  • selfdrive/debug/car/에 차량별 분석 스크립트
system/loggerd/ tools/lib/route.py selfdrive/debug/car/

❌ 현재 불가능한 것

불가 신경망 모델 온디바이스 재학습

driving_vision.onnx, driving_policy.onnx는 고정된 사전학습 모델. comma 3x에서 직접 재학습 불가 (연산 자원 부족, 데이터 수천 시간 필요).
selfdrive/modeld/models/driving_vision.onnx selfdrive/modeld/models/driving_policy.onnx

불가 개인 운전 스타일 자동 학습

"내가 이 구간에서 이렇게 운전했으니 다음에도 그렇게"와 같은 개인화 학습은 없음. longitudinal MPC의 비용 함수는 고정. 사용자 프로파일 시스템 없음.

단방향 comma.ai 서버 데이터 업로드

주행 로그는 uploader.py를 통해 api.commadotai.com으로 업로드됨. comma.ai가 이 데이터로 다음 버전 모델을 학습하지만:
  • 개인 맞춤 모델이 기기로 돌아오지 않음
  • fleet 전체 모델 개선에만 기여
  • 개인 운전 습관 반영 없음
system/loggerd/uploader.py common/api.py

🚗 실질적인 권장 사항 (Azera 기준)

충분한 주행으로 자동 학습 수렴시키기

  • 100km+ 주행 — steerRatio, 각도 오프셋이 Azera에 최적화됨
  • 다양한 커브 주행 — torqued 데이터 포인트 4,000개 이상 축적
  • 고속도로 직선 — calibrationd가 카메라 각도 정밀화
  • 학습된 파라미터는 /persist/에 저장되어 재시동 후에도 유지

운전 습관 반영이 필요하다면

현재 코드에서 직접 수정 가능한 항목:
  • long_mpc.py — 앞차 추종 거리, 가감속 비용 함수 가중치
  • longcontrol.py — PID kP/kI 브레이크포인트
  • 변경 후 commit/push하면 기기 업데이트 시 적용
